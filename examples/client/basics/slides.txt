SECTION B — SHARED CONTEXT (read before the scripts)

B.1 What JUB is
- A platform (FastAPI + MongoDB) to publish OBSERVATORIES: browsable
  collections of products (files, photos, reports) and data.
- Everything is described with shared vocabularies called CATALOGS.
- Everything is searchable with a small query language (the DSL).
- The client is the Python package `jub` (module jub.client.v2), async.

B.2 The running example: car photos
Folder source/cars has 8 photos named brand_model_color_year.jpg:

    ford_mustang_blue_1968.jpg
    mitsubishi_eclipse_black_1998.jpg
    mitsubishi_eclipse_red_1998.jpg
    mitsubishi_eclipse_white_1998.jpg
    nissan_gtr_blue_1998.jpg
    nissan_gtr_white_1998.jpg
    toyota_supra_black_1997.jpg
    toyota_supra_red_1997.jpg

(!) The file name alone is enough to build the whole observatory:
    catalogs, products, tags and search.

B.3 How to run
- Stack running locally (MongoDB, Xolo auth service, API on port 5000).
- Config file examples/client/.env.examples:
      JUB_API_URL=http://localhost:5000
      JUB_USERNAME=invitado
      JUB_PASSWORD=invitado
- Run the scripts IN ORDER, 03 -> 12. Each one uses what the previous ones
  created:
      python examples/client/basics/03_catalogs.py
      ...
      python examples/client/basics/12_review_observatory.py

B.4 Boilerplate shared by every script (show once, in section C)

    import asyncio, os
    import jub.dto.v2 as DTO
    from jub.client.v2 import JubClientBuilder

    USERNAME       = os.environ["JUB_USERNAME"]
    OBSERVATORY_ID = f"cars_{USERNAME}"

    def item_id(value: str) -> str:
        return f"{value}_{USERNAME}"

    async def main() -> None:
        client = (await JubClientBuilder(API_URL, USERNAME, PASSWORD)
                  .build()).unwrap()
        ...

    asyncio.run(main())

B.5 Three conventions to explain early
(!) Every client call returns a Result: Ok(value) or Err(error).
    .unwrap() gives the value; check .is_err before if it may fail.
    Errors are values, not exceptions.
(!) We choose our own ids and suffix them with the username:
    cars_invitado, TOYOTA_invitado. This way the later scripts know every
    id without looking it up, and several users can share one server.
- The client is async: every call is awaited inside asyncio.run(main()).

B.6 DIAGRAM — core concepts (use in section C)

    Catalog  --contains-->  Catalog item (value, code, aliases, children)
    Observatory --links--> Catalog
    Observatory --links--> Product --tagged with--> Catalog item
    Observatory --links--> Data source --records use--> Catalog items
    Observatory --links--> Service

(!) Things exist on their own and are connected by LINKS. The same catalog
    or product can belong to several observatories.

SECTION D — SCRIPT 03: CATALOGS (5 frames)

Goal: create the vocabularies used by tags, search and data records.

D.1 TABLE "Catalogs are vocabularies" — what 03 creates

    Catalog     Type       DSL block  Items
    CAR_BRAND   INTEREST   VI         FORD, MITSUBISHI, NISSAN, TOYOTA
                                      (models as children: MUSTANG, ECLIPSE,
                                       GTR, SUPRA)
    CAR_COLOR   INTEREST   VI         BLACK, BLUE, RED, WHITE (+ GOLD)
                                      aliases: NEGRO, AZUL, ROJO, BLANCO,
                                      DORADO
    CAR_YEAR    TEMPORAL   VT         Y1968, Y1997, Y1998
    COUNTRY     SPATIAL    VS         MX, US, JP, DE, KR

Each catalog item has:
- value      used in queries (UPPER_SNAKE_CASE)
- code       a number (for years: the year itself)
- aliases    other names for the same item (ROJO = RED)
- children   a hierarchy (a brand's models)

D.2 Frame "Items from file names"
bullets:
- Parse brand, model, color, year from each file name
- Build unique lists of brands, colors, years
code:

    def parse(image: Path) -> tuple[str, str, str, int]:
        """toyota_supra_red_1997.jpg -> ("TOYOTA", "SUPRA", "RED", 1997)"""
        brand, model, color, year = (
            part.upper().replace("-", "_") for part in image.stem.split("_"))
        return brand, model, color, int(year)

    def item(value, code, name="", **extra) -> DTO.CatalogItemCreateDTO:
        return DTO.CatalogItemCreateDTO(
            catalog_item_id = item_id(value),
            name            = name or value.replace("_", " ").title(),
            value           = value,
            code            = code,
            value_type      = "STRING",
            **extra,
        )

D.3 Frame "A catalog with a hierarchy: brands -> models"
bullets:
- Models are children of their brand
- (!) Children let VI(CAR_BRAND.TOYOTA.*) also match SUPRA
code:

    brand_items = []
    for code, brand in enumerate(brands, start=1):
        models = sorted({m for b, m, _, _ in cars if b == brand})
        children = [item(m, code * 100 + i)
                    for i, m in enumerate(models, start=1)]
        brand_items.append(item(brand, code, children=children))

    await client.create_catalog(DTO.CatalogCreateDTO(
        catalog_id   = f"brands_{USERNAME}",
        name         = "Car brands",
        value        = "CAR_BRAND",
        catalog_type = "INTEREST",
        items        = brand_items,
    ))

D.4 Frame "Aliases and temporal items"
bullets:
- Aliases: another name for the same item (Spanish)
- (!) Temporal items need value_type="DATETIME" + temporal_value
- That date is what makes VT(>= 1997) work
code (two short blocks):

    aliases = [DTO.CatalogItemAliasCreateDTO(
        value="ROJO", value_type="STRING", description="Spanish")]
    color_items.append(item("RED", code, aliases=aliases))

    DTO.CatalogItemCreateDTO(
        catalog_item_id = item_id("Y1997"),
        name            = "1997",
        value           = "Y1997",
        code            = 1997,
        value_type      = "DATETIME",
        temporal_value  = "1997-01-01T00:00:00Z",
    )

Also mention in one line: the COUNTRY catalog is created the same way,
with catalog_type = "SPATIAL".

D.5 Frame "Extend a catalog later"
bullets:

- Add an alias to an existing item

F.3 Frame "Upload one file (07)"

code:

    job = (await client.upload_product(product_id, str(image))).unwrap()

    task = (await client.get_task(job.job_id)).unwrap()
    while task.current_status in ("pending", "running"):
        await asyncio.sleep(1)
        task = (await client.get_task(job.job_id)).unwrap()

    content = (await client.download_product(product_id)).unwrap()
    print(content == image.read_bytes())   # True

F.4 Frame "Many files, retries, no duplicates (09)" — bullets only

- wait_uploads(workers, max_retries): send the queue in parallel
- max_retries = total attempts per file (1 = no retry)
- (!) The registry file remembers successes: 2nd run skips all

G.4 TABLE "The query language (DSL)"
A query is "jub.v1." followed by one or more blocks:

    Block   Dimension   Question   Matches items of type
    VS(..)  spatial     where?     SPATIAL    (COUNTRY)
    VT(..)  temporal    when?      TEMPORAL   (CAR_YEAR), supports > >= < <= =
    VI(..)  interest    what?      INTEREST   (CAR_BRAND, CAR_COLOR)

Rules (as bullets under the table):
- Inside a block: AND / OR
- Between blocks: always AND
- Write items as CATALOG.VALUE: VI(CAR_COLOR.RED)
- * = no filter for that block

G.5 Frame "DSL by example" — a minted {text} block with comments

    jub.v1.VI(CAR_BRAND.TOYOTA)                   # Toyota
    jub.v1.VI(CAR_BRAND.TOYOTA AND CAR_COLOR.RED) # red Toyota
    jub.v1.VI(CAR_BRAND.TOYOTA.*)                 # Toyota + its models
    jub.v1.VI(CAR_COLOR.ROJO)                     # alias -> RED
    jub.v1.VT(>= 1997)                            # 1997 or later
    jub.v1.VT(>= 1997 AND <= 1998)                # a range
    jub.v1.VS(COUNTRY.JP)                         # Japanese cars
    jub.v1.VS(COUNTRY.JP).VI(CAR_COLOR.RED)       # red AND Japanese
    jub.v1.VS(*)                                  # any place = no filter

Then 3 alert bullets (can be a second frame "Three traps"):
(!) VS(*) means "any place": it returns every product, even untagged ones
(!) VI(CAR_BRAND.TOYOTA) does NOT match SUPRA; use TOYOTA.* for children
(!) Values are matched by name in ALL catalogs: always pass observatory_id
